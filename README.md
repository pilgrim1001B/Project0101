# FDD

FDD — небольшой компилятор целочисленного языка. Исходный текст разбирается в AST из `record`-узлов, а генератор обходит AST с помощью pattern matching и создаёт исполняемый IL через `System.Reflection.Emit`.

## Запуск

### Окно редактора (без команд для запуска программ)

Соберите проект GUI один раз командой:

```powershell
dotnet build .\gui\fdd-gui.csproj -c Release
```

После этого запускайте `gui\bin\Release\net10.0-windows\fdd-gui.exe` двойным щелчком. В окне можно писать программу, нажать **«Запустить»**, а также открывать и сохранять файлы `.fdd`. Пример программы уже загружен при запуске.

### Через терминал

```powershell
dotnet build
dotnet run -- .\program.fdd
dotnet run -- -e "print 2 + 3 * 4;"
```

Файл программы должен содержать операторы, разделённые точкой с запятой:

```text
let total = 0;
let i = 1;
while (i <= 5) {
    total = total + i;
    i = i + 1;
}
if (total == 15) {
    print total;
} else {
    print 0;
}
```

Поддерживаются объявления `let`, присваивания, `print`, блоки `{ ... }`, `if`/`else`, `while`, целые числа `Int32`, переменные, унарные `+`, `-`, `!`, арифметические `+`, `-`, `*`, `/`, `%`, сравнения `==`, `!=`, `<`, `<=`, `>`, `>=` и логические `&&`, `||`. В условиях ноль означает ложь, любое ненулевое число — истину; логические операторы вычисляются с коротким замыканием. Области видимости блоков локальные.

Ошибки синтаксиса и необъявленные переменные выводятся с номером строки. Арифметика выполняется над `Int32`; деление на ноль приводит к стандартной ошибке времени выполнения .NET.
